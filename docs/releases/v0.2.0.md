# StashDrop 0.2.0

This release fixes the force close when turning on the floating bubble, makes Circle to Search StashDrop's own (no more Gemini), and lets you change setup and the default assistant from inside the app. Android version code is **3**; Android 9 (API 28) or newer is required.

## Fixed

- **No more force close when starting the floating bubble.** The bubble's shader could not draw on the software-rendered overlay window; overlays are now hardware accelerated, with a safe fallback.
- **Swipe up opens Circle to Search**, not Gemini.
- Moving the bubble never triggers a search by accident.

## New

- **Use StashDrop as your digital assistant:** long-press home to circle anything on screen. Set it or restore your previous assistant in Settings.
- **In-app setup:** floating bubble, notifications, Shizuku, screenshot access, and assistant, each with a one-tap fix. With Shizuku, one button sets up everything.
- **Haptics** when dragging the bubble, drawing a circle, stacking cards, and dropping, with a toggle in Settings.
- **Circle to Search** replaces Circle Studio: search circled text on Google, search the image with Lens, copy, stash, or share.
- A new round floating bubble and single-line layouts throughout.
