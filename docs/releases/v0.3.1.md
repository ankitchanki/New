# StashDrop 0.3.1

Fixes the "Background task failed" error and the force close after touching the floating bubble, adds a drag-to-dismiss X, and lets Google Circle to Search work with StashDrop as the digital assistant. Android version code is **5**.

## Fixed

- **Floating bubble errors:** its slide-to-edge and peek animations ran without a frame clock, which caused "Background task failed" (and, before 0.3.0, a force close a few seconds after touching the bubble). Fixed and covered by tests.
- **Circle to Search from the bubble** no longer shows "Background task failed".

## New

- **Drag to dismiss:** drag the bubble to the X at the bottom of the screen to hide it, like chat heads.
- **Google Circle to Search with StashDrop as assistant:** in Settings → Digital assistant, tap **Connect** (needs Shizuku). The corner swipe and long-press home then open Google Circle to Search through StashDrop.
