# StashDrop 0.7.0

A quieter edge shelf: one movable handle, a smaller panel, fewer controls, swipe deletion and nearby compatible sharing targets.

## Changes

- One subtle handle on your chosen edge. Drag it left/right or vertically; the edge and height are remembered after restart. The mirrored handle and count badge are removed.
- Smaller rectangular shelf: at most 296 × 420 dp and 78% width / 58% height. No StashDrop heading or repeated Inbox/Images labels; the hold-to-drag hint uses small text. Real previews and content filters remain.
- Swipe a card horizontally for a red trash background and delete icon. A confirmation protects saved files; cancel keeps the item. Main Shelf supports this too.
- Dragging cards reveals up to four installed apps advertising support for the exact payload action/MIME. Hover enlarges icons; drop opens that app's share composer with URI grants. Past choices through this target strip rank suggestions; no system Recents/usage-history access. Final upload/send is controlled by the receiving app and user.
- Home pairs the actual app logo with StashDrop, retains Everything within reach, removes the promotional subtitle and duplicate setup shortcut, and puts navigation in a floating pill.
- The search strip has no permanent marker drawing. One strip toggle replaces redundant swipe/hold/double-tap/overlay-corner choices. System corner swipe opens the assistant settings path; Android/OEM support controls the native gesture.
- Interaction settings open at the top without inheriting the previous page scroll. Removed a 220 ms pre-search animation wait. Actual Google launch latency still needs phone measurement.

## Update

Install `StashDrop-v0.7.0.apk` over the official app. Version code **10**, package `com.vibe.stashdrop`, Room schema and original production signing identity are retained. Existing saved items stay available. Inbox means items without a custom collection, not a duplicate or a second storage location.

The app cannot hide Android status-bar icons or replace mandatory bottom navigation. Choose the single side handle for unobtrusive persistent access; enable native assistant corner gestures in your phone settings where supported. Google decides whether its interface is Circle to Search or Gemini.

## Verification and limits

The public `release-verification.json` records automated test/lint results, original-certificate continuity, APK/AAB signatures and 16 KB alignment checks. Gallery images render actual production components with fixtures, not phone screenshots. No physical POCO F5 or emulator was attached. Receiver-specific drop behavior, native corner support and real launch latency remain physical test items.
