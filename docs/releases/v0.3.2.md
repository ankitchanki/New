# StashDrop 0.3.2

Same app as 0.3.1 (bubble fixes, drag-to-dismiss X, Google Circle to Search through StashDrop as assistant), retaining the **original StashDrop production signing key** for compatible updates. Android version code is **6**; Android 9 (API 28) or newer is required.

## Install

Install the APK over an earlier build signed with the original production key to preserve the local shelf. Debug builds or builds signed with a different certificate cannot be updated in place; share out anything you want to keep before uninstalling them, because uninstalling deletes the local shelf.

The original production certificate's SHA-256 fingerprint is `dbb75d23fd05e5cc228b039d4734c693235b07f0f7605bfe9ce206e4a2b59272`. The release verifier requires this identity before publication.

## What's in it

- Fixed "Background task failed" and the force close a few seconds after touching the floating bubble.
- Drag the bubble to the X at the bottom of the screen to hide it.
- Google Circle to Search from the bubble, bottom swipe, notification, and, with Settings → Digital assistant → Connect (Shizuku), from the corner swipe or long-press home while StashDrop is the assistant.
- Crash reports with a Copy button if anything goes wrong.
