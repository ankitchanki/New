# StashDrop 0.3.2

Same app as 0.3.1 (bubble fixes, drag-to-dismiss X, Google Circle to Search through StashDrop as assistant), now signed with a **new signing key**. Android version code is **6**; Android 9 (API 28) or newer is required.

## Install

Because the signing key changed, **uninstall any earlier StashDrop once** before installing this APK. Uninstalling deletes the local shelf, so share out anything you want to keep first. Later updates install normally over this one.

## What's in it

- Fixed "Background task failed" and the force close a few seconds after touching the floating bubble.
- Drag the bubble to the X at the bottom of the screen to hide it.
- Google Circle to Search from the bubble, bottom swipe, notification, and, with Settings → Digital assistant → Connect (Shizuku), from the corner swipe or long-press home while StashDrop is the assistant.
- Crash reports with a Copy button if anything goes wrong.
