# StashDrop 0.3.2

A native Android floating shelf for notes, clean links, files, and screen cutouts. Keep saved material close with a movable bubble, use Google's Circle to Search on eligible devices or StashDrop's built-in capture/OCR workflow, and share useful selections back to other apps.

**[Download the signed APK](https://github.com/ankitchanki/StashDrop/releases/download/v0.3.2/StashDrop-v0.3.2.apk)** · Android 9+ · Version code **6**

## Release scope

Version 0.3.2 has the same app features and fixes as 0.3.1 and retains the **original StashDrop production signing key** for compatible updates. It also validates signing inputs before Gradle: copied whitespace and accidental extra Base64 encoding are handled; invalid keys, passwords, aliases, or a different certificate stop publication early.

## Highlights carried forward from 0.3.1

- Fixed "Background task failed" and the force close shortly after touching the floating bubble by supplying its animations with the Compose frame clock.
- Added a bottom X target: drag the bubble onto it to hide the overlay.
- Added Google Circle to Search through StashDrop as assistant: **Settings → Digital assistant → Connect**, with authorized Shizuku, keeps Google's voice service active while supported assistant gestures enter StashDrop. Google still determines eligibility.
- Local crash reports have a Copy button to help diagnose unexpected closes.

## Included features

| Feature | How it works |
| --- | --- |
| Floating shelf | Tap the draggable, edge-peeking bubble for saved cards; hold it to search; select multiple cards to share |
| Notes, links, files, collections | Add notes or share into StashDrop; recognized tracking parameters are removed from text links; attachments are copied into private storage |
| Native Google route | Requests Google's contextual search from the bubble, enabled gestures, notification, or Settings; Google controls the resulting UI |
| Built-in circle screen | Capture with Shizuku/accessibility or system consent, draw a lasso, and process Latin text/barcodes on device |
| Result actions | Search text, use Lens, copy, stash, or share a cutout; Lens/Share also save the cutout locally |
| Clipboard auto-stash | Optional text monitoring, off by default, with recent-copy deduplication; background availability varies |
| Sharing and drag | Android Share, WhatsApp actions, and global card-stack drag with temporary attachment grants; receiver support is required |
| Motion and settings | Aurora/metaball effects with older-Android fallbacks, springiness adjustment, haptic toggle, and configurable gesture strips |

## First run

1. Open **Settings → Setup**, allow the floating bubble, and check notification access. Shizuku is optional; start/authorize it before using its setup shortcuts.
2. Tap **Show floating bubble** on Home. Tap for the shelf; hold to search. Bottom strips and swipe-up default on while the overlay runs; other strip gestures default off.
3. Keep **Use Google Circle to Search** on for Google's route, or turn it off for StashDrop's built-in lasso/OCR. If Gemini opens instead, turn it off.
4. Add notes from Shelf or share text/files into StashDrop. Auto-stash copied text remains off unless you enable it.

## Install and signature continuity

Install the APK over an earlier build signed with the original production key to preserve the local shelf. Debug builds or builds signed with a different certificate cannot be updated in place; share out anything you need before uninstalling them, because uninstalling deletes local data. The app has no in-app archive restore or cloud sync.

The original production certificate's SHA-256 fingerprint is:

```text
dbb75d23fd05e5cc228b039d4734c693235b07f0f7605bfe9ce206e4a2b59272
```

Only the public certificate is distributed; private signing keys and passwords are kept separately.
