# StashDrop 0.3.0

Google Circle to Search is back, crashes are guarded and reported, and the digital assistant can be picked by hand. Android version code is **4**; Android 9 (API 28) or newer is required.

## Circle to Search

- **Google's own Circle to Search** opens from the bubble (hold), the bottom swipe strip, the notification, and Settings → Try it now. Keep **Google** as your digital assistant for this. Google decides which phones get Circle to Search; if it opens Gemini instead, switch to StashDrop's circle screen in Settings.
- **Digital assistant:** Settings → Digital assistant → Open assistant picker lets you choose StashDrop by hand. With StashDrop chosen, the corner swipe or long-press home opens StashDrop's circle screen (search with Google, Lens, copy, stash, share).

## Fixes

- Floating bubble touches, drags, the shelf, and drag-and-drop can no longer close the app; problems are shown instead.
- Circling again or capturing twice no longer crashes the circle screen.
- Back closes the floating shelf; copied text is no longer auto-stashed twice.

## If something still goes wrong

StashDrop now saves crash reports. Open the app after a crash, tap **Copy report**, and send it.
