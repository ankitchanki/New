# StashDrop 0.1.1

This release adds automated signed distribution and fixes the floating shelf, Circle Studio, screen-on restoration, and collection filtering. Android version code is **2**; Android 9 (API 28) or newer is required.

## Changes

- Keep taps within the floating shelf from dismissing it through the backdrop.
- Reuse one saved Circle Studio cutout across Stash, Lens, and Share.
- Restore the floating dock after screen-on when the device has no active lock screen.
- Reset the Shelf filter to All when its selected collection disappears.
- Build and validate with GitHub Actions, then publish signed release artifacts from matching version tags.
- Verify the signing certificate matches the original StashDrop production identity before publication.

The initial floating shelf, local notes/links/files, offline OCR/barcode tools, optional Shizuku integration, and Compose motion remain available. See the [complete changelog](https://github.com/ankitchanki/StashDrop/blob/main/CHANGELOG.md), [initial release notes](https://github.com/ankitchanki/StashDrop/blob/main/docs/releases/v0.1.0.md), and [UI gallery](https://github.com/ankitchanki/StashDrop/blob/main/docs/UI_GALLERY.md).

## Installation and validation

Install the APK, allowing installation from your download source. A production-signed 0.1.0 installation can be updated in place. Debug installations use another certificate and cannot be updated with this APK; uninstalling them deletes their local stash data.

Build/signature checks do not certify phone behavior. Overlay permissions, privileged calls, native Google eligibility, clipboard restrictions, external drag/drop, and device performance still require [device testing](https://github.com/ankitchanki/StashDrop/blob/main/docs/DEVICE_VALIDATION.md). Optional capture features require the appropriate Android permissions or consent; protected content cannot be captured.
