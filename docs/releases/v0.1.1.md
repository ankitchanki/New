# StashDrop 0.1.1

The first published StashDrop build: everything from 0.1.0, plus bug fixes and an automated release pipeline.

## Fixed

- Taps inside the floating shelf sheet no longer close it.
- Circle Studio Stash, Lens, and Share reuse one saved cutout instead of saving duplicates.
- The Shelf collection filter falls back to "All" when its collection disappears.
- Floating overlays reappear after screen-on on devices without a lock screen.

## Assets

| Asset | Purpose |
| --- | --- |
| `StashDrop-v0.1.1.apk` | Signed, minified release APK for Android 9+ |
| `StashDrop-v0.1.1.aab` | Signed Android App Bundle; not directly installable |
| `SHA256SUMS.txt` | Checksums for the release files |

## Install

Download the APK and allow installation from your chosen source. Android 9 (API 28) or newer is required. The floating shelf needs overlay access; Shizuku, accessibility screenshots, gesture strips, and auto-stash are optional. A debug build installed earlier has a different signature and must be uninstalled first, which deletes its local stash.

See [CHANGELOG.md](https://github.com/ankitchanki/StashDrop/blob/main/CHANGELOG.md) for the full change list.
