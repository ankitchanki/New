# StashDrop 0.6.0

This release addresses touch blocking while the floating shelf is active, moves search gestures away from system navigation, and adds a compact edge shelf with real media previews and content filters.

## Fixed

- Idle aurora/dismiss windows are hidden. Their opacity is now safe in combination while visible: two 0.35-alpha windows combine to 0.5775, below Android’s standard 0.8 input-blocking threshold. The previous two 0.7 windows combined to 0.91 and could stop other apps receiving touches.
- Search markers sit above stable navigation insets, with side markers inset from Android Back gestures. Side arrows show the intended up/inward direction. Start on those raised markers; physical bottom-edge swipes remain Android Home/Recents gestures.
- Stopping during a search hand-off cannot recreate gesture windows. Canceled handle drags do not open the shelf. A bounded panel handles its own content; outside touches can dismiss it and reach the other app.

## Added and changed

- Slim controls on both screen edges replace the circular bubble. Tap or pull inward to open a rectangular floating panel on that side, hold for Google search, move vertically or drag to X to hide.
- Actual local image/sticker previews and best-effort video representative-frame thumbnails in the main Shelf and floating panel. Local off-thread decoding, EXIF orientation, at-most-320-pixel thumbnails, offscreen reference release and a 12 MiB cache limit preview memory. Missing/unsupported media gets a placeholder.
- All / Images / Videos / Stickers / URLs / OTP / Text / Files type filters combine with collections. Changing filters clears selection and preserves saved content.
- Sticker candidates use GIF/WebP MIME or a `Stickers` collection; `Images`/`Photos` collections override that image heuristic. OTP filtering recognizes code-like text, not a guaranteed semantic classification. GIF previews are still frames.
- Gesture markers support portrait and landscape, and hide on lock or with the keyboard. Google-only search routing remains unchanged.
- Updated eight production component renders, current usage/platform guides and POCO F5 / Android 15 test instructions.

## Update and use

Install `StashDrop-v0.6.0.apk` over a compatible official install. Version code is **9**; package, Room schema and the original production signing certificate are preserved. Existing saved content remains available.

Allow **Edge shelf**, then tap **Show edge shelf** on Home. Enable desired search gestures under **Settings → Gestures, clipboard & feel** and begin on the raised markers, not Android’s bottom edge. For Google search, choose Google as digital assistant and enable **Use screen and app data**. Google controls native Circle to Search availability and can show Gemini instead.

## Verification

The signed local build passed **66 host tests**, eight rendering checks, debug/release lint with zero errors, original-certificate continuity, APK/AAB signature checks and 16 KB ZIP/native-library alignment. The downloadable `release-verification.json` records the executed CI counts and lint warnings.

No physical POCO F5 or other phone/emulator was attached to the cloud. Real-device input, Google eligibility, codec behavior and performance need the [device checklist](https://github.com/ankitchanki/StashDrop/blob/main/docs/DEVICE_VALIDATION.md). The updated [Windows ADB helper](https://github.com/ankitchanki/StashDrop/blob/main/docs/WINDOWS_DEVICE_TESTING.md) installs the verified public APK and captures local logs.
