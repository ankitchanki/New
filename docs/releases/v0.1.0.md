# StashDrop 0.1.0

The first StashDrop release brings a local Android productivity shelf, Circle Studio, and spring-driven Compose UI to Android 9+.

## Highlights

- Floating thumb dock, magnetic edge snap/peek, and one-handed stash sheet.
- Notes, cleaned links, imported images/files, collections, and sharing.
- Lasso cutouts with bundled Latin-script text recognition and barcode scanning.
- Optional Shizuku capture, assistant management, background text clipboard, and best-effort native Google search.
- Aurora/metaball shaders, Canvas fallbacks, velocity-based card motion, and haptics.
- Overview, Shelf, Controls, a motion playground, and a documented source-rendered UI gallery.
- Neutral project attribution throughout reachable release history.

## Install

Download the APK and allow installation from your chosen download source. Android 9 (API 28) or newer is required. Existing debug installations have a different signing certificate and cannot be updated in place with this release key; uninstalling a debug build deletes its local stash data.

The floating shelf requires overlay access. Shizuku, accessibility screenshots, gesture strips, and auto-stash are optional. Auto-stash is off by default.

## Validation and limits

See the attached verification report and [CHANGELOG.md](https://github.com/ankitchanki/StashDrop/blob/main/CHANGELOG.md) for build/signature checks and the complete change list. Phone behavior, native Google eligibility, OEM clipboard rules, external drag/drop acceptance, and real-device performance have not been certified. This initial release does not claim universal Circle to Search support or a protected-content capture bypass.
