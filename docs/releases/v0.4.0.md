# StashDrop 0.4.0 — the SVG design, built for Android

The StashDrop SVG concept now has a native Jetpack Compose implementation: refreshed Home, selectable Shelf cards, clearer setup, a dedicated interaction settings page, and updated built-in circle-search styling. Actions connect to the app's existing local storage, Android sharing, capture/OCR, assistant integration, and floating service.

**[Download the signed APK](https://github.com/ankitchanki/StashDrop/releases/download/v0.4.0/StashDrop-v0.4.0.apk)** · Android 9+ · Version code **7**

## New native UI

- Home uses the concept's typography, dark surfaces, periwinkle/mint accents, rounded cards, bubble controls, search route summary, and recent-item entry points.
- Tap cards in Shelf to select multiple items. The reachable selection bar provides Share, WhatsApp, Move to collection, Delete, and Clear selection.
- Move a selection to a named collection. Changing a collection filter clears selection; opening a recent Home item reveals it in the full Shelf.
- Permanent deletion requires confirmation, including deletion from the floating shelf. Cancel keeps items intact.
- Settings separates access/setup cards, search mode, assistant controls, and **Gestures, clipboard & feel**. Assistant details expand when tapped.
- The interaction page contains the existing gesture switches, clipboard monitor preference, haptics, and springiness slider. Enabling copied-text saving now requires explicit confirmation about retaining sensitive text.
- Circle to Search has updated headings, rounded capture presentation, result status, and a reminder that Lens/Share also save a cutout.
- The floating shelf places the selected stack and sharing actions below its scrolling cards for easier reach.

## Real app behavior

The native application uses actual Room/private-file storage, Android share intents, Shizuku when authorized, consent-based capture fallbacks, and bundled on-device Latin OCR/barcode processing. The downloadable SVG prototype remains a separate simulation and design reference. Native lists scroll; the prototype's pagination and sample import/recognition are not production features.

Google still controls native Circle to Search eligibility. If Gemini opens instead, turn **Use Google Circle to Search** off for StashDrop's built-in capture/lasso route. Protected content cannot be bypassed, and other apps decide whether sharing or a global drop is accepted.

## First run / update

1. Install the APK over an earlier official build signed with the original production certificate. The package name and Room schema are unchanged, preserving the existing shelf on compatible updates.
2. Open **Settings → Setup** to review bubble, notification, optional Shizuku, and screenshot access.
3. Use Home to show the bubble; tap it for the shelf and hold to search.
4. Open **Settings → Gestures, clipboard & feel** for gesture, clipboard, haptic, and spring settings.
5. Select Shelf cards for batch actions. Use **More selection actions** for Move or Delete.

Debug/differently signed builds cannot update in place. Share out important items before uninstalling an incompatible build; there is no app archive restore or cloud sync.
